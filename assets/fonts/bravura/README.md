# Bravura

Bravura version 1.482 by Steinberg Media Technologies GmbH is bundled unchanged
as `Bravura.woff2`. It is licensed under the SIL Open Font License 1.1; see
[OFL.txt](OFL.txt). It supplies actual SMuFL music glyphs for classroom notation
and Rhythm Fishing. No external font service is required during play.

Source: https://github.com/steinbergmedia/bravura

Downloaded from:
https://raw.githubusercontent.com/steinbergmedia/bravura/master/redist/woff/Bravura.woff2

Bundled file SHA-256:
`e68df66446e3ffa6f474ce9eb2949e938102406f12d8f40ad8754398c50f55d4`

Glyph names/codepoints follow the W3C SMuFL metadata:
https://github.com/w3c/smufl/blob/gh-pages/metadata/glyphnames.json

Bravura uses 1,000 units per em, with four staff spaces per em. Staff clefs and
noteheads are positioned from that musical coordinate system, rather than
from a text font's line box.

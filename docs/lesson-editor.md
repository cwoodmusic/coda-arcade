# Developer lesson editor

Open the developer console and choose **Lessons**. The editor starts with
**Lesson cards · teaching & practice**, which edits the short classroom lessons.

- **Lesson title, introduction & sections** changes the category title, opening
  text, section names, and Basics/Advanced arrangement. Save these with **Save
  lesson settings**.
- Each card exposes its title, teaching text, example, first practice question,
  answers, correct answer, feedback, and follow-up checks. Add, remove, duplicate,
  reorder, or move cards between sections. Follow-up checks can be added, removed,
  and reordered independently.
- **Lesson visuals** offers **Notes & staff**, **Clef**, and **Piano keyboard**.
  Notes use the score editor. Clefs include treble/bass signs and staff reminders.
  Keyboards allow key highlights, sharp/flat spelling, and picture descriptions.
  **Keyboard text and labels** lets you hide note names and captions or rewrite
  the black-key group and pitch-direction captions.
  **Add visual** places more pictures on the same card or practice check.
- **Interactive activity instructions** edits the older guided activities.
  Their text and static pictures can be replaced or removed; answer controls
  continue to operate as part of the activity.

**Save teaching card**, **Save step**, and **Save question** apply the selected
draft in this browser. Reopen the classroom lesson to use the saved version.
Navigation preserves unsaved card drafts. Undo/Redo operates on saved changes.
**Export content JSON** backs up the saved course, including lesson structure,
follow-up checks, and visuals; **Import content JSON** restores it. Site-wide
content is published through `education-content.json`.

Authoring data is separate from player progress. Existing official assessment
results remain intact, and edited assessments use their own attempt records.

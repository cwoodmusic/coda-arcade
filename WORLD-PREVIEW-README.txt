CODA ARCADE CONNECTED WORLD

Open index.html for the title screen. Play as guest enters world-preview.html,
the main connected arcade. The original arcade is at classic-arcade.html.

The connected world includes playable cabinets, the Piano Lab, the music
classroom, Rhythm Fishing, the boutique, the Notes shop, NPC missions and
character progression. Cabinets open their games inside the arcade.

Use Developer (F2) to edit objects, collision, foreground/background layers,
dialogue and artwork. Pixel editor provides fullscreen, 64x zoom, straight
lines and an eyedropper for backgrounds, assets and animated characters.
The Piano Lab and fishing cave have their own Developer controls.

Developer edits save locally. Export the complete world-project JSON to keep
a portable backup or share a layout. Editing in the console does not publish
the site's source files or replace another browser's saved project.

See START-HERE.md for current controls, classroom profile entry and local
server instructions. Browser tests use temporary servers and guest storage.

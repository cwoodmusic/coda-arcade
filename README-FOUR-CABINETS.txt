Coda Arcade — Four Cabinet Edition

Upload all files and folders in this ZIP to the root of the existing Coda Arcade GitHub Pages repository, preserving paths. The song-machine folder stays nested.

Four cabinets are laid out at x=205,395,605,795, two on each side of the disco ball. Song Machine opens inside the existing game frame, using Return to Arcade. Jukebox Compose and Edit also open Song Machine in that frame.

This package includes the latest local song-cloud.js sign-in fix. Firebase rules need no changes.

Browser and live Firebase behavior have not been tested.
